**Xcode 코드 편집 단축키 모음**

안녕하세요! 오늘은 Xcode에서 코드 편집을 더욱 효율적으로 할 수 있도록 도와주는 단축키들을 소개하려고 합니다. 이 단축키들을 활용하면 코드 작성, 수정, 리팩토링을 더욱 빠르고 편리하게 할 수 있습니다.

1. **주석 처리**

- **Cmd + /**: 현재 줄 또는 선택된 영역의 주석 처리/해제

1. **코드 들여쓰기 및 내어쓰기**

- **Cmd + [**: 선택된 영역의 코드를 왼쪽으로 들여쓰기
- **Cmd + ]**: 선택된 영역의 코드를 오른쪽으로 내어쓰기

1. **코드 이동**

- **Option + Cmd + [**: 선택된 코드 블록을 위로 이동
- **Option + Cmd + ]**: 선택된 코드 블록을 아래로 이동

1. **코드 복사 및 삭제**

- **Cmd + C**: 선택된 영역의 코드 복사
- **Cmd + X**: 선택된 영역의 코드 잘라내기
- **Cmd + D**: 현재 줄 또는 선택된 영역의 코드 복제

1. **코드 선택**

- **Cmd + L**: 특정 줄로 이동 및 선택
- **Cmd + Shift + L**: 현재 줄 전체 선택

1. **자동 완성**

- **Ctrl + Space**: 자동 완성 목록 표시

1. **코드 접기 및 펼치기**

- **Cmd + Option + Left Arrow**: 선택된 영역의 코드 접기
- **Cmd + Option + Right Arrow**: 선택된 영역의 코드 펼치기
- **Cmd + Option + Shift + Left Arrow**: 모든 코드 접기
- **Cmd + Option + Shift + Right Arrow**: 모든 코드 펼치기
